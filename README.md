# How Supermarkets Trick Your Brain Into Spending More (Randos in 60s)

> **Also in this repo:** production bible for *Why Passenger Jets Are Not Electric* (photoreal 3D documentary): [`projects/why-passenger-jets-are-not-electric/`](projects/why-passenger-jets-are-not-electric/README.md)

## Project layout

```
index.html                 root composition, GENERATED by tools/build.mjs (scene slots + audio stems)
compositions/s01…s07.html  one HyperFrames sub-composition per story section (modular, editable alone)
assets/lib/rig.js          drawing + motion library: character rig, props, backgrounds,
                           camera moves, transitions, kinetic type, cue helpers, SFX cue logging
assets/lib/gsap.min.js     GSAP 3.14.2 (vendored, no network at render time)
assets/fonts/              Patrick Hand / Patrick Hand SC (SIL OFL)
assets/voice/Lxx.wav       one narration clip per script line (Kokoro TTS)
assets/audio/              narration / music / sfx stems + synthesized SFX library (sfx/)
script/script.json         THE source of truth for narration (text, TTS spellings, pauses)
timeline/timing.json       measured line + section timings (built from the voice clips)
timeline/sfx_events.json   every sound effect, with absolute time, collected from the scenes
timeline/shots.json        every shot cut, with absolute time
tools/                     pipeline scripts (see below)
docs/                      deliverables
```

## How the pipeline works

```
script/script.json
   │  python3 tools/tts.py (HeyGen Evan, or Kokoro)   → assets/voice/*.wav, assets/audio/narration.wav, timeline/timing.json
   ▼
timeline/timing.json
   │  node tools/build.mjs                          → index.html + injects each scene's cue table (/*CUES*/ … /*ENDCUES*/)
   ▼
compositions/sXX.html  (animations are keyed to q("L23", "phrase") = when that phrase is spoken)
   │  node tools/collect_sfx.mjs                    → timeline/sfx_events.json + shots.json (runs every scene headless)
   │  python3 tools/audio.py                        → sfx library, sfx stem, music stem (ducked under the voice)
   ▼
npx hyperframes render -o out/render_raw.mp4 --quality high --crf 18 --workers 4
   │  bash tools/master.sh                           → loudness-normalised final MP4 (−14 LUFS, −1 dBTP)
   ▼
out/how-supermarkets-trick-your-brain.mp4
```

All timing comes from the measured voice clips. If you edit a line in `script/script.json` and re-run the chain, every animation, sound effect and section boundary follows the new timing automatically.

### Rebuild from scratch

Requirements: Node 22 or newer, Python 3.11 or newer, and FFmpeg.

```bash
pip install kokoro-onnx soundfile numpy scipy
# Kokoro v1.0 model files (Apache-2.0):
#   https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx
#   https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin
npx hyperframes auth login --device             # HeyGen sign-in (premium voice)
python3 tools/tts.py --force                     # skip: voice clips are already committed
node tools/build.mjs
NODE_PATH=$(npm root -g) node tools/collect_sfx.mjs   # needs `playwright` installed (npm i -g playwright)
python3 tools/audio.py
npx hyperframes@0.8.157 browser ensure
npx hyperframes@0.8.157 render -o out/render_raw.mp4 --quality high --crf 18 --workers 4
bash tools/master.sh
```

On a 4-core cloud box a full render takes about 60–80 minutes. Use `--quality draft` for quick previews. For one scene, run `node tools/build.mjs --only s03`, then `npx hyperframes render -c preview-s03.html`.

### Editing a scene

- Preview it live: `npx hyperframes preview`. Snapshot frames with `tools/snap.sh s04 3,7,12` (times are local to the scene).
- Each scene builds its shots with `S.add(name, svg, htmlOverlay)`, then lists them with `R.shots(tl, [[selector, time, transition], …])`.
- Characters: `R.person(id, {shirt, hair, hairColor, coat, glasses, mouth, flip})`, animated with `R.pose`, `R.expr`, `R.laugh`, `R.talk`, `R.walk`, `R.flutter` and `R.idle`.
- Times: `q("L28", "how hard")` returns the moment that phrase is spoken.
- Sound: `sfx("pop", t, gain)` adds a sound effect. Re-run `collect_sfx.mjs` and `audio.py` afterwards.

## Facts and sources

The narration sticks to published findings. Sources are listed in `docs/youtube_package.md`: Goldman's 1937 shopping cart and hired shoppers; Milliman 1982 (slow music, ≈38% more sales than fast music); North, Hargreaves & McKendrick 1997 (French/German music, ≈5:1 French wine); Anderson & Simester 2003 ($39 beat $34, sale signs); Xu, Schwarz & Wyer 2015 (hunger and non-food purchases); Duhigg 2012 (Target's pregnancy score); England's 2022 placement rules; FMI (≈31,700 items per store). Claims that are weaker or partly practical are hedged in the script, e.g. milk at the back is "partly practical" and products on end caps "tend to" sell more.
